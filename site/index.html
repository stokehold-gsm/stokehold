Панель для игровых серверов поверх LinuxGSM

Один бинарник и SQLite вместо PHP, MySQL, Redis и Docker. Подхватывает серверы LinuxGSM, которые у вас уже стоят, без переустановки. Для админов сообществ на одном VPS.

Обсудить в Discord GitHub

Discord из России открывается через обход блокировок. Баги и вопросы можно оставлять и в GitHub.

Зачем это

Подхват, а не переустановка

Панель находит скрипты LinuxGSM у выбранного пользователя и управляет ими. Чужие аккаунты она не трогает, пока владелец сам не внесёт их в список.

Лёгкая установка

Установщик проверяет подпись релиза и контрольные суммы до установки, а если новая версия не запустилась, возвращает прежнюю. Работает на одном маленьком VPS.

Безопасность по умолчанию

Привилегированная часть выполняет только фиксированный набор операций. Файлы серверов открываются через один модуль с защитой от выхода за каталог. Вход с двухфакторной защитой.

Что уже работает

Проверено на Ubuntu 22.04. Ранняя версия: список короткий и точный.

  • запуск, остановка, перезапуск, статус, проверка обновления и бэкап сервера LinuxGSM из веб-интерфейса;
  • поиск и добавление уже установленных серверов (режим подхвата);
  • вход по паролю (argon2id), двухфакторная защита TOTP, роли owner, admin и viewer, защита от CSRF;
  • русский и английский интерфейс;
  • установщик с проверкой подписи, откатом при неудачном обновлении и удалением;
  • установка новых серверов из каталога LinuxGSM, редактор конфигов, расписание бэкапов, перезапусков и проверок обновлений;
  • мониторинг процессора, памяти, диска и состояния серверов;
  • в закрытой сборке Pro: REST API, несколько машин через агента, список модов Factorio, уведомления и команды в Discord, публичная страница состояния.

Пока нет: установка модов с портала, вайпы из интерфейса, бэкапы в S3, откат обновления игры, автообновление панели. Тесты на реальных играх пока только на Minecraft и Factorio.

Установка

Выберите, где у вас будет работать панель. Установщик проверяет подпись релиза до установки, его можно прочитать перед запуском.

Ubuntu 22.04 и новее, Debian 12 и новее. Процессор x86_64 или ARM64, определяется сам.

sudo apt update && sudo apt install -y curl openssl
curl -fsSL https://dl.stokehold.online/install.sh -o install.sh
less install.sh        # прочитайте, выход: q
sudo bash install.sh

В конце установщик напечатает ссылку вида https://АДРЕС:8443/setup?code=…. Откройте её в браузере: браузер предупредит о сертификате (панель сама его создала, пока нет домена), нажмите «Дополнительно» и продолжите. Дальше создаёте владельца и входите в панель. Если страница не открывается, откройте TCP-порт 8443 у хостинга или в файрволе.

Подойдёт любой Linux с systemd и OpenSSL 3 (Fedora, Rocky/Alma 9, Arch и другие). Автоустановка зависимостей игр работает только на Ubuntu и Debian, для остальных систем зависимости ставятся по документации LinuxGSM.

# Fedora, Rocky, Alma: sudo dnf install -y curl openssl
# Arch: sudo pacman -S --needed curl openssl
curl -fsSL https://dl.stokehold.online/install.sh -o install.sh
less install.sh
sudo bash install.sh

Панель работает только на Linux. Два пути: арендовать небольшой VPS с Ubuntu 24.04 и ставить по вкладке «Ubuntu / Debian», либо запустить Linux внутри Windows (WSL2). Для WSL2 нужен Windows 10 22H2 или 11. Команды в PowerShell от имени администратора:

wsl --install -d Ubuntu-24.04

После перезагрузки откройте Ubuntu и включите systemd:

printf '[boot]\nsystemd=true\n' | sudo tee /etc/wsl.conf

Выполните в PowerShell wsl --shutdown, снова откройте Ubuntu и дальше ставьте по вкладке «Ubuntu / Debian». Ссылку из вывода установщика можно открыть в браузере Windows; если адрес не открывается, замените его на localhost. Игровые серверы в WSL2 недоступны снаружи без проброса портов, поэтому для настоящего сервера выбирайте VPS.

Панель работает только на Linux, поэтому на Mac нужен Linux где-то рядом. Надёжнее всего арендовать небольшой VPS с Ubuntu 24.04 и ставить по вкладке «Ubuntu / Debian». Для пробы подойдёт виртуальная машина с Ubuntu 24.04 (UTM, Multipass): внутри неё команды те же, а адрес панели зависит от сетевых настроек машины.

ssh ВАШ_ПОЛЬЗОВАТЕЛЬ@АДРЕС_VPS

Дальше ставите так же, как на вкладке «Ubuntu / Debian».

Обновление и удаление

Обновление: запустите установщик ещё раз, прежняя версия вернётся сама, если новая не запустится. Удаление не трогает ваши игровые серверы.

curl -fsSL https://dl.stokehold.online/uninstall.sh -o uninstall.sh
sudo bash uninstall.sh

Вопросы

Нужен ли Discord, чтобы панель работала?

Нет. Панель, лицензии и обновления от Discord не зависят.

Бесплатно ли это?

Да. Ядро панели открыто под AGPL-3.0 и бесплатно, без лимита серверов. Платный Pro (закрытая сборка) добавляет API, несколько машин, моды, Discord и другое. Цены не объявлены.

Что отправляется на ваш сервер?

Free ничего не отправляет. У Pro для проверки ключа уходят ключ, отпечаток экземпляра и версия панели. Подробности будут в политике обработки данных.
