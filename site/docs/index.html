Документация

Версия 0.1, ранний доступ. Здесь только то, что уже работает. Чего ещё нет, перечислено в конце раздела «Что это».

Что это

Stokehold GSM это веб-панель для игровых серверов поверх LinuxGSM. Один бинарник и SQLite, без Docker, PHP и баз данных. Панель вызывает скрипты LinuxGSM и показывает результат, поддерживает всё, что умеет LinuxGSM (143 игры на момент проверки). Игровые серверы работают под обычными пользователями Linux, как в самом LinuxGSM.

Из двух частей: панель (веб-интерфейс, без прав root) и helper (служба от root с фиксированным набором операций; именно она запускает команды LinuxGSM). Панель не может ничего, кроме того, что разрешено helper.

Чего пока нет: установка модов с портала, вайпы из интерфейса, бэкапы в S3, откат обновления игры, автообновление самой панели. Тесты на реальных играх пока только на Minecraft и Factorio.

Установка

Нужен Linux с systemd и OpenSSL 3 (Ubuntu 22.04 и новее, Debian 12 и новее), процессор x86_64 или ARM64, доступ root. На Windows и macOS панель напрямую не ставится: нужен VPS с Linux или WSL2 (см. главную страницу).

sudo apt install -y curl openssl && curl -fsSL https://dl.stokehold.online/install.sh | sudo bash

Что делает установщик:

  1. проверяет подпись релиза и хеши файлов, при любой ошибке останавливается, ничего не меняя;
  2. ставит stokehold и stokehold-helper в /usr/local/bin;
  3. создаёт пользователя stokehold, каталог /var/lib/stokehold и файл настроек /etc/stokehold/stokehold.env;
  4. создаёт и запускает службы stokehold-helper и stokehold;
  5. открывает порт 8443 в ufw, если он включён, и печатает ссылку первой настройки.

Прочитать установщик заранее: скачайте install.sh и запустите sudo bash install.sh. Параметры установщика: --channel stable|beta, --version vX.Y.Z, --no-start.

Первый вход

  1. В конце установки в консоли появится ссылка вида https://АДРЕС:8443/setup?code=…. Откройте её в браузере. Код в ссылке одноразовый.
  2. Браузер предупредит о сертификате: панель создаёт собственный, пока у вас нет домена. Нажмите «Дополнительно» и продолжите. Отпечаток сертификата установщик печатает рядом со ссылкой, его можно сверить.
  3. Введите почту и пароль владельца (не короче 10 символов). Страница работает один раз: после создания владельца открыть её повторно нельзя.
  4. Сразу включите двухфакторную защиту: «Безопасность» → «Начать настройку». Добавьте секрет в приложение-аутентификатор (Aegis, FreeOTP, любое TOTP), введите шестизначный код и нажмите «Включить».
Ссылку потеряли? Код всегда есть в журнале: sudo journalctl -u stokehold | grep "setup code". Каждый перезапуск службы до создания владельца выдаёт новый код. Если страница не открывается, откройте TCP-порт 8443 у хостинга.

Подхват существующих серверов

Если на машине уже стоит сервер LinuxGSM, переустанавливать ничего не нужно. Панель не вправе управлять чужими аккаунтами сама: владелец машины вносит имя пользователя в файл, который читает helper и который панель изменить не может.

echo factorio | sudo tee -a /etc/stokehold/adopt.conf

Затем на странице «Добавить сервер» введите это имя пользователя Linux, нажмите «Найти серверы» и добавьте нужный скрипт (fctrserver, mcserver и т. п.). Файл читается при каждом запросе, перезапуск не нужен. Подхваченный сервер получает режим adopted. Панель ничего не устанавливает в такой аккаунт и не создаёт пользователей. Имена: одно на строку, без пробелов, не root.

Новый сервер из каталога

«Установить новый сервер»: выберите игру из каталога LinuxGSM и название. Панель создаст отдельного пользователя gs_…, поставит пакеты, которые LinuxGSM указывает для игры (на Ubuntu и Debian), и установит сервер. Ход установки виден на странице, идёт одна установка за раз. Если не удалось, причина в журнале: повторите с тем же или другим названием.

  • Для Steam-игр LinuxGSM иногда просит дополнительные пакеты: поставьте их вручную по подсказке.
  • Для Minecraft перед первым запуском примите EULA: в редакторе файлов откройте serverfiles/eula.txt и поставьте eula=true.

Расписания

У каждого сервера есть страница «Расписание»: бэкап, перезапуск или проверка обновления каждый день в заданное время (по UTC) или каждые N часов. Если панель была выключена в назначенное время, действие выполнится один раз после запуска. Результат последнего запуска виден на той же странице. Менять расписание могут owner и admin, viewer только смотрит.

Бэкап LinuxGSM останавливает игровой сервер, поэтому выбирайте время без игроков.

Редактор конфигов

Ссылка «Файлы» у сервера открывает правку конфигов. Доступны только каталоги serverfiles и lgsm/config-lgsm и только текстовые файлы до 256 КБ. Перед сохранением панель оставляет копию прошлой версии рядом (.stokehold-bak). Изменения вступают в силу после перезапуска сервера. Редактор не создаёт новых файлов и не следует символическим ссылкам. Файлы видят и меняют только owner и admin: в конфигах бывают пароли.

Файловый менеджер

Ссылка «Файлы» у сервера открывает всю папку игрового пользователя: можно ходить по папкам, создавать папки и пустые файлы, загружать и скачивать файлы, переименовывать, перемещать и удалять. Доступно ролям owner и admin. Таблица сортируется по имени, размеру и дате изменения, папки всегда идут первыми.

  • Загрузка: несколько файлов сразу, до 256 МБ за раз. Файл появляется на месте только после последней части, оборванная загрузка не портит старую версию.
  • Скачивание: потоком, размер не ограничен.
  • Правка: у текстовых файлов внутри serverfiles и lgsm/config-lgsm (до 256 КБ) есть ссылка «Изменить» с копией прошлой версии в .stokehold-bak.
  • Удаление: всегда с отдельным подтверждением, можно выбрать несколько элементов (до 200). Корзины нет, папки удаляются целиком.
Менеджер видит только домашнюю папку игрового пользователя и не выходит из неё ни через .., ни через символические ссылки. Скрыты .ssh, .bashrc, .profile и authorized_keys. Все изменения и скачивания пишутся в журнал.

Мониторинг

Страница «Мониторинг» показывает процессор, память, диск, нагрузку за минуту и состояние каждого сервера (в том числе число игроков, если LinuxGSM его печатает для этой игры). Раз в минуту панель снимает замер и спрашивает у LinuxGSM details. В памяти хранятся последние 60 замеров, после перезапуска панели график начинается заново. Работает на Linux, потому что читает /proc. Мониторинг открыт всем тарифам.

Владелец создаёт пользователей на странице «Пользователи»: пароль генерируется и показывается один раз, передайте его лично. Там же сброс пароля и 2FA и удаление. Последнего владельца удалить нельзя. Каждый меняет свой пароль на странице «Безопасность», остальные его сессии при этом завершаются. Язык интерфейса переключается RU/EN в шапке.

Безопасность

  • Пароли хранятся как argon2id. После нескольких неверных паролей учётная запись блокируется на 15 минут, число попыток с адреса ограничено.
  • Двухфакторная защита TOTP: каждый код работает один раз. Отключение требует пароль.
  • Защита от CSRF, строгая политика содержимого страниц, cookie с флагами HttpOnly, SameSite и Secure.
  • Привилегированный helper принимает только фиксированный набор операций и выполняет их для разрешённых пользователей. Все его операции пишутся в журнал (journalctl -u stokehold-helper).
  • Файлы серверов открываются через один модуль, защищённый от выхода за каталог.
  • Игровые серверы работают под обычными пользователями, без контейнеров: это проще и легче, но изоляция слабее, чем в Docker.

HTTPS и домен

Сразу после установки панель отвечает по HTTPS на порту 8443 со своим сертификатом (браузер предупредит один раз). Это временное решение, пока нет домена. Когда домен появится, поставьте обратный прокси, например Caddy: он сам получит доверенный сертификат.

panel.example.com {
    reverse_proxy 127.0.0.1:8080
}

Затем в /etc/stokehold/stokehold.env замените -tls-listen :8443 на -trust-proxy и перезапустите:

sudo systemctl restart stokehold

Порт 8443 после этого закроется, а адрес клиента будет браться из заголовка прокси. Не включайте -trust-proxy без прокси: заголовок можно подделать.

Лицензия и тарифы

Страница «Лицензия» показывает тариф, включённые функции и срок. Free: всё открытое ядро (AGPL-3.0) без лимита серверов, ключ не нужен, обращений к серверу лицензий нет. Pro и Hosting это закрытая сборка с дополнительными функциями (ниже); Hosting добавляет несколько машин. Цены пока не объявлены.

  • Ключ вводит владелец на странице «Лицензия». Что отправляется на сервер лицензий (ключ, отпечаток экземпляра, версия панели), написано на самой странице.
  • Сервер лицензий недоступен: игровые серверы продолжают работать, платные функции работают до конца срока последнего подтверждения и ещё 30 дней.
  • Лицензия закончилась: пропадают только платные функции, игровые серверы не останавливаются никогда.

REST API Pro

«Ключи API» → создать ключ. Он показывается один раз и хранится в базе только в виде хеша. Ключ действует с ролью того, кто его создал: у наблюдателя только чтение, у владельца и админа ещё и управление. Каждое действие по ключу пишется в журнал; после пяти неверных ключей с одного адреса за минуту включается ограничение.

curl -H "Authorization: Bearer shapi_..." https://panel.example.com/api/v1/servers
curl -X POST -H "Authorization: Bearer shapi_..." https://panel.example.com/api/v1/servers/3/restart
curl -H "Authorization: Bearer shapi_..." https://panel.example.com/api/v1/metrics
ЗапросЧто делает
GET /api/v1/serversсписок серверов, состояние, игроки, машина
GET /api/v1/servers/{id}один сервер
POST /api/v1/servers/{id}/{действие}details, start, stop, restart, backup, check-update
GET /api/v1/metricsпоследний замер машины

Несколько машин Hosting

Игровые серверы на других машинах управляются из той же панели через небольшого агента stokehold-agent. Агент принимает запросы панели по HTTPS на порту 9443 (откройте его только для адреса панели), при первом запуске делает самоподписанный сертификат и печатает его отпечаток; секрет лежит в /var/lib/stokehold-agent/secret. Для существующих аккаунтов LinuxGSM на этой машине создайте /etc/stokehold/adopt.conf, как и на главной.

В панели: «Машины» → добавить, ввести адрес, отпечаток и секрет. Панель сверяет отпечаток при каждом соединении, поэтому центр сертификации не нужен. Дальше при установке и добавлении сервера появляется выбор машины. Расписания, редактор конфигов и состояние работают для серверов на любой машине. Машину с серверами удалить нельзя.

Пока нельзя переносить сервер между машинами; мониторинг показывает только главную машину.

Моды Factorio Pro

У сервера Factorio в списке есть ссылка «Моды». Она читает serverfiles/mods/mod-list.json и включает или выключает моды, остальные поля файла (например, версию) не трогает. Сами файлы модов кладёте вы: скачивания с портала модов панель не делает, потому что порталу нужны ваши логин и токен, а хранить их в панели мы не хотим. Для других игр страница так и скажет.

Игровые инструменты Pro

Ссылка «Игровые инструменты» в меню «⋯» сервера открывает страницу с вкладками. Работает для Minecraft Java (сервер mcserver и PaperMC pmcserver) и Factorio; доступна владельцу и админу.

Версия и ядро Minecraft

  • Смена версии. Список версий берётся у Mojang (релизы или снапшоты) или у PaperMC. Панель записывает версию в настройки LinuxGSM (mcversion, для Vanilla ещё branch) и запускает команду update, дальше загрузкой занимается сам LinuxGSM.
  • Другое ядро. На сервере mcserver можно поставить Paper, Purpur или Fabric: панель скачивает файл ядра на место minecraft_server.jar и записывает это в serverfiles/stokehold-core.json. Forge и NeoForge помечены «скоро»: им нужен запуск установщика.
  • Осторожно. Команда LinuxGSM update может заменить поставленное ядро ванильным. Для Paper и Purpur панель закрепляет версию, чтобы этого не произошло, для Fabric такой защиты нет, поэтому не запускайте update вручную. Вернуться к Vanilla можно на той же странице.
  • Перед сменой панель предлагает сделать бэкап и просит подтвердить перезапуск. Ход операции виден по шагам, при ошибке остановленный сервер запускается обратно.

Плагины и моды

Поиск по каталогу Modrinth с фильтром по ядру (плагины для Paper и Purpur, моды для Fabric) и версии игры. «Установить» скачивает файл в serverfiles/plugins или serverfiles/mods и проверяет контрольную сумму. Установленные файлы можно удалить там же. Нужные зависимости панель только называет, ставить их надо отдельно. После установки перезапустите сервер. У Vanilla плагинов и модов нет.

Быстрые настройки

Формы с проверкой значений для server.properties Minecraft (описание, число игроков, сложность, режим, PvP, online-mode, дальность прорисовки, белый список, зерно мира) и настроек Factorio (название, описание, игроки, пароль, видимость, команды). Меняются только перечисленные значения, остальное в файле остаётся. Пароль Factorio на страницу не возвращается: пустое поле оставляет прежний. Изменения вступают в силу после перезапуска сервера.

Список версий и загрузки идут только с официальных источников (Mojang, PaperMC, Purpur, Fabric, Modrinth) через helper.

Discord и публичная страница Pro

Уведомления

«Интеграции» → адрес вебхука. Панель пишет туда, когда сервер запустился или остановился. Принимаются только адреса discord.com/api/webhooks/….

Команды бота

Команды /servers, /server и /metrics даёт собственный бот сообщества. Создайте приложение в Discord Developer Portal и ключ API на панели, затем запустите stokehold-bot с переменными:

DISCORD_BOT_TOKEN=...  DISCORD_PUBLIC_KEY=...  DISCORD_APP_ID=...
STOKEHOLD_PANEL_URL=https://panel.example.com
STOKEHOLD_PANEL_TOKEN=shapi_...
STOKEHOLD_CONTROL_ROLE="Server Admin"

/servers может вызвать любой участник сервера, /server <название> <действие> и /metrics только участники с ролью из STOKEHOLD_CONTROL_ROLE. Бот видит панель только через ключ API, пароли ему не нужны.

Публичная страница состояния

«Интеграции» → «Публичная страница состояния». Без входа по адресу /status видны названия серверов и состояние, больше ничего.

Обновление и удаление

Обновление: запустите команду установки ещё раз. Старые файлы сохраняются; если новая версия не ответила на проверку работоспособности за 20 секунд, установщик возвращает прежнюю, перезапускает службы и сообщает об этом. Удаление не трогает ваши игровые серверы и их пользователей.

curl -fsSL https://dl.stokehold.online/uninstall.sh | sudo bash

Без --purge данные панели остаются в /var/lib/stokehold и /etc/stokehold.

Если что-то не работает

Сначала смотрите журнал: journalctl -u stokehold -u stokehold-helper -e.

Панель не открывается

  • curl -s http://127.0.0.1:8080/health на самой машине должен ответить ok. Нет ответа: systemctl status stokehold.
  • Страница по ссылке установщика не открывается: откройте TCP-порт 8443 у хостинга и в файрволе.
  • Вход не проходит при верном пароле, а страница открыта по обычному HTTP: cookie с флагом Secure не отправляются. Открывайте по HTTPS.
  • После нескольких неверных паролей учётная запись блокируется на 15 минут.

Забыт код настройки

sudo journalctl -u stokehold | grep "setup code". Он печатается при запуске, пока нет ни одного пользователя; перезапуск службы выдаёт новый.

«Служебный процесс недоступен»

systemctl status stokehold-helper, сокет /run/stokehold/helper.sock должен принадлежать stokehold с правами srw-------. Журнал helper показывает каждую операцию.

«Не удалось найти серверы этого пользователя»

Пользователь не внесён в /etc/stokehold/adopt.conf, либо у него нет lgsm/config-lgsm/<имя>server (LinuxGSM не установлен). Для аккаунтов, созданных helper, имя должно начинаться с gs_.

Команда завершилась с ошибкой

Результат показан на странице. Типичные причины: не хватает зависимостей (Missing dependencies, поставьте названные пакеты); сервер уже запущен или остановлен; LinuxGSM каждый раз скачивает свои модули с GitHub, и без доступа к GitHub команды зависают.

Сообщить о проблеме

В GitHub Issues или в Discord: версия панели (stokehold version), ОС, игра и лог без паролей, токенов и ключей лицензий.

Частые вопросы

Нужен ли Docker?

Нет. Игровые серверы работают под обычными пользователями Linux, как в LinuxGSM.

Можно подхватить уже работающий сервер?

Да, см. «Подхват существующих серверов». Ничего не переустанавливается и не перезаписывается.

Что с обновлениями игры?

Проверка обновления есть. Откат из снимка и закрепление версии в планах.

Что отправляется на ваши серверы?

Free не обращается к нашим серверам и не требует ключа. Единственный исходящий запрос: раз в несколько часов панель спрашивает у GitHub, вышла ли новая версия (GitHub видит адрес сервера); это можно выключить в настройках обновлений. Pro для проверки ключа отправляет ключ, публичный ключ экземпляра и версию панели.

Нужен ли Discord, чтобы панель работала?

Нет. Панель, лицензии и обновления от Discord не зависят.

Как проверить, что скачанное настоящее?

Установщик сам проверяет подпись релиза и хеши. Если подпись не сходится, установка прекращается до любых изменений.
