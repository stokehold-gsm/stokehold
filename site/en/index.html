A game server panel on top of LinuxGSM

One binary and SQLite instead of PHP, MySQL, Redis and Docker. It adopts the LinuxGSM servers you already run, no reinstall. Built for community admins on a single VPS.

Join the Discord GitHub

Why

Adopt, don't reinstall

The panel finds LinuxGSM scripts for a chosen user and drives them. It never touches other accounts until the owner lists them.

Light to install

The installer verifies the release signature and checksums before installing, and rolls back if the new version fails to start. Runs on one small VPS.

Secure by default

The privileged part runs a fixed set of operations only. Server files go through one module that cannot escape the server directory. Two-factor sign-in.

What works today

Verified on Ubuntu 22.04. This is a prototype, not a release; the list is short and exact.

  • start, stop, restart, status, update check and backup of a LinuxGSM server from the web UI;
  • finding and adding servers that are already installed (adopt mode);
  • sign-in with argon2id passwords, TOTP two-factor, owner/admin/viewer roles, CSRF protection;
  • Russian and English interface;
  • an installer with signature verification, rollback on a failed upgrade, and uninstall.

Not yet: a mod manager, scheduled backups and wipes, S3 backups, game update rollback, a public status page, Discord notifications, paid licences.

FAQ

Do I need Discord for the panel to work?

No. The panel, licences and updates do not depend on Discord.

Is it free?

The plan is a free tier for one game server and a paid Pro tier. Prices are not announced.

What is sent to your server?

Free sends nothing. Pro sends the key, an instance fingerprint and the panel version to verify the licence. Details will be in the privacy policy.

Who builds it?

One developer who runs a Factorio server. The project is written with an AI assistant; a human makes the decisions and releases.
