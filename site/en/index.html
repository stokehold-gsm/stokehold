A game server panel on top of LinuxGSM

One binary and SQLite instead of PHP, MySQL, Redis and Docker. It adopts the LinuxGSM servers you already run, no reinstall. Built for community admins on a single VPS.

Join the Discord Documentation GitHub

Why

Adopt, don't reinstall

The panel finds LinuxGSM scripts for a chosen user and drives them. It never touches other accounts until the owner lists them.

Light to install

The installer verifies the release signature and checksums before installing, and rolls back if the new version fails to start. Runs on one small VPS.

Secure by default

The privileged part runs a fixed set of operations only. Server files go through one module that cannot escape the server directory. Two-factor sign-in.

What works today

Verified on Ubuntu 22.04. An early version: the list is short and exact.

  • start, stop, restart, status, update check and backup of a LinuxGSM server from the web UI;
  • finding and adding servers that are already installed (adopt mode);
  • sign-in with argon2id passwords, TOTP two-factor, owner/admin/viewer roles, CSRF protection;
  • Russian and English interface;
  • an installer with signature verification, rollback on a failed upgrade, and uninstall;
  • installing new servers from the LinuxGSM catalogue, a config editor, scheduled backups, restarts and update checks;
  • monitoring of CPU, memory, disk and server states;
  • in the closed Pro build: REST API, several machines through an agent, the Factorio mod list, Discord notifications and commands, a public status page.

Not yet: installing mods from the portal, wipes from the UI, S3 backups, game update rollback, panel self-update. Real-game tests so far cover Minecraft and Factorio only.

Install

Pick where the panel will run, copy the command and run it on the server. At the end the installer shows a link: open it and finish the setup in your browser.

Ubuntu 22.04 or newer, Debian 12 or newer. x86_64 or ARM64.

sudo apt install -y curl openssl && curl -fsSL https://dl.stokehold.online/install.sh | sudo bash

Any Linux with systemd and OpenSSL 3. Install curl and openssl with your package manager first (dnf, pacman). Game dependencies are installed automatically on Ubuntu and Debian only.

curl -fsSL https://dl.stokehold.online/install.sh | sudo bash

The panel runs on Linux only: rent an Ubuntu 24.04 VPS (Ubuntu / Debian tab) or run Linux inside Windows with WSL2. In PowerShell as administrator:

wsl --install -d Ubuntu-24.04

After the reboot open Ubuntu and enable systemd:

printf '[boot]\nsystemd=true\n' | sudo tee /etc/wsl.conf

Then run wsl --shutdown in PowerShell, open Ubuntu again and use the command from the Ubuntu / Debian tab. Game servers in WSL2 are not reachable from outside, so use a VPS for a real server.

The panel runs on Linux only. On a Mac, rent an Ubuntu 24.04 VPS, connect to it and run the command from the Ubuntu / Debian tab.

ssh YOUR_USER@VPS_ADDRESS

The browser warns about the certificate: the panel makes its own until you have a domain. Choose "Advanced" and continue. If the page does not open, open TCP port 8443 at your host.

Read the installer, update, uninstall

The installer verifies the release signature before installing. To read it first, download install.sh and run it with sudo bash install.sh. Update: the same command. Uninstalling does not touch your game servers.

curl -fsSL https://dl.stokehold.online/uninstall.sh | sudo bash

FAQ

Do I need Discord for the panel to work?

No. The panel, licences and updates do not depend on Discord.

Is it free?

Yes. The core is open source (AGPL-3.0) and free, with no server limit. Paid Pro, a closed build, adds the API, several machines, mods, Discord and more. Prices are not announced.

What is sent to your server?

Free never contacts our servers and needs no key. The only outgoing request is a check with GitHub every few hours for a newer version (GitHub sees the server address); you can turn it off in the update settings. Pro sends the key, an instance fingerprint and the panel version to verify the licence. Details will be in the privacy policy.

Who builds it?

One developer who runs a Factorio server. The project is written with an AI assistant; a human makes the decisions and releases.
