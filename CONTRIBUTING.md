# Как помочь проекту

- Баги и идеи: issues в репозитории или канал в Discord.
- Код: небольшие pull request-ы, с тестом. `gofmt`, `go vet ./...`, `go test ./...` должны проходить.
- Каждый коммит с `Signed-off-by` (см. `legal/cla.md`, это черновик): без согласия с CLA изменения принять нельзя.
- Не добавляйте зависимости ради нескольких строк; лицензия зависимости должна быть совместима с AGPL-3.0.
- Об уязвимостях пишите владельцу приватно, не в публичный issue.
- Название и логотип: `legal/trademark.md`.
