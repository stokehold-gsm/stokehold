# 0007. Код Pro закрыт, ядро открыто

Дата: 2026-10-31. Заменяет ADR 0006.

Договорённость с владельцем с самого начала: Free открыт (AGPL-3.0), Pro закрыт. В ADR 0006 я отступил от неё из-за спешки и выложил платные функции в открытое ядро. Это было ошибкой, и здесь она исправлена.

## Как устроено
- Публичный репозиторий собирается и работает без Pro. Для Pro есть три шва: `internal/web/free.go` (заглушки), `editionTables` в хранилище и интерфейс бота. Страницы Pro в Free-сборке просто не существуют: маршруты отвечают 404, ссылок в меню нет.
- Приватный репозиторий `stokehold-gsm/stokehold-pro` повторяет структуру каталогов и содержит файлы с `//go:build pro`: API и ключи, машины и агент, менеджер модов, вебхук Discord, публичную страницу статуса, команды Discord к панели, их тесты и шаблоны.
- Pro собирается наложением приватного дерева на чистый чекаут публичного (`build.sh` в приватном репозитории) с `-tags pro`. Тесты Pro гоняются на объединённом дереве.
- Лицензионные проверки остаются и в Pro: лицензия включает функции, но код закрыт.

## Что остаётся открытым
Панель, мониторинг, helper, установщик, расписания, редактор конфигов, бот сообщества, сервер лицензий. Имена функций (`pkg/license/features.go`) тоже открыты: это не секрет.

## Чего этим не исправить
Код Pro был в публичной истории и в релизе v0.1.0 с момента публикации. Историю я переписал и релиз заменил, но любой, кто успел клонировать или скачать, копию сохранил. Назад это не вернуть. Практически это значит: Pro защищён лицензией и поддержкой, а не секретностью старых версий. Новые функции Pro теперь в публичный репозиторий не попадают.
