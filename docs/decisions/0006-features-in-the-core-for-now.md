# 0006. Платные функции пока в одном репозитории

Дата: 2026-10-31.

В ADR 0005 платные функции должны были жить в закрытом модуле. Закрытого репозитория пока нет, а владелец хочет выпустить API, несколько машин, менеджер модов и вебхук Discord. Я написал их здесь же, в пакете `web` (`pro.go`, `api.go`, `status.go`), и каждую проверяю по лицензии: страницы отвечают 402, API тоже.

Что это значит честно. Исходники функций открыты под AGPL, и любой, кто соберёт панель сам, может убрать проверку. Лицензия продаёт официальную подписанную сборку, обновления и поддержку, а не секретность кода. Для админов небольших сообществ этого хватает; хостингам, которым нужна изоляция, всё равно нужна поддержка.

Если понадобится настоящая закрытость, файлы `internal/web/pro.go`, `api.go`, `status.go` и страницы из `pages_pro.html` переносятся в приватный репозиторий за хуком `//go:build pro`, как в ADR 0005. Перенос механический: функции связаны с остальной панелью через `s.has(feature)` и `s.gated(...)`. Решить это нужно до того, как репозиторий станет публичным, потому что после публикации код уже не отозвать.

Не закрыто в этом ADR: S3-бэкапы и откат обновлений игр. Их ещё нет.
