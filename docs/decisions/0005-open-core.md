# 0005. Open core под AGPL-3.0

Статус: принято владельцем (2026-10-31).

## Решение
- Ядро панели (всё, что есть в этом репозитории) открыто под **AGPL-3.0**. Free = всё ядро, без лимита на число серверов.
- Платные функции Pro живут в **закрытом модуле** (отдельный приватный репозиторий): бэкапы в S3, откат обновлений игр, несколько админов с аудитом, статус-страница, менеджер модов, интеграция с Discord, REST API; в тарифе Hosting ещё несколько узлов.
- Сервер лицензий, его админка и CLI тоже в приватном репозитории: они не нужны тем, кто просто ставит панель.
- Токен лицензии несёт список функций (`pkg/license/features.go`), а не число серверов.
- Имя и логотип Stokehold не входят в лицензию кода, см. `legal/trademark.md`.

## Почему
- Админам сообществ важно, что панель с правами root можно прочитать. Это главный аргумент доверия.
- AGPL не даёт хостерам взять код и продавать закрытый форк-сервис, не открывая изменений.
- Платят за удобство и за поддержку, а не за закрытость ядра.

## Цена решения
- Любой может собрать ядро сам и, в пределах AGPL, менять его. Закрыть функции Pro в ядре нельзя, поэтому они вынесены в отдельный модуль.
- Вклады со стороны требуют CLA (`legal/cla.md`), иначе позже нельзя будет выпускать Pro и ядро под другой лицензией. Черновик, нужен юрист.
- Релизная сборка с подписью владельца остаётся единственной «официальной»: на неё распространяется EULA.
