# 0004. Онлайн-активация лицензии

Дата: 2026-10-31. Статус: принято по предложению владельца.

Контекст: первоначально предлагалась чисто офлайн-проверка подписанного ключа. Ограничения: нельзя отозвать ключ без связи, нельзя считать инстансы, а данные об инстансах нужны для админки (фаза 4).

Решение: онлайн-активация с коротким подписанным токеном (7 дней), суточное продление, грейс 30 дней. Free-тариф не обращается к серверу.

Дополнение (2026-10-31): подробная модель угроз и дизайн ключей - docs/security-licensing.md. Главное: Free = 1 сервер и без обращений к нашему серверу; ключ - случайные 128 бит, на сервере хеш; ключ инстанса и токен привязаны друг к другу; иерархия корневой (офлайн) и онлайн-ключ; сервер лицензий отдаёт только подписанные данные, никогда команды.

Следствия:
- В политике ПДн и в доках описываем, что уходит на сервер: ключ, отпечаток машины, версия панели; IP виден серверу.
- Сервер лицензий обязателен с первого релиза Pro.
- Офлайн-ключи для закрытых сетей не делаем, вернёмся по запросу пользователей.
