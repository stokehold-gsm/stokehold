# 0008. Проверка новой версии включена по умолчанию

Дата: 2026-11-01.

Раньше мы обещали, что Free ничего не отправляет наружу, а проверка обновлений выключена по умолчанию. Владелец попросил, чтобы панель сама сообщала о новой версии, иначе уведомление никто не увидит: люди ставят панель один раз и не заходят на страницу обновлений.

Что сделано. По умолчанию режим «сообщать»: панель через 30 секунд после запуска и затем раз в 6 часов спрашивает у GitHub список выпусков и показывает владельцу плашку на главной странице и в шапке. Ничего не ставится без нажатия кнопки. Автоматическая установка остаётся отдельным режимом, выключена. Режим «Выключено» останавливает все запросы.

Цена. GitHub, третья сторона, видит адрес сервера. Нашему серверу ничего не уходит. Это раскрыто на странице обновлений, в FAQ, документации, на сайте и в политике обработки данных (`legal/privacy.md`, чернавик, до юриста). Установщик и так обращается к GitHub при каждой установке.
