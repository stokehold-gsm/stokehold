# 0003. Роль «сотрудник магазина» (выдача лицензий)

Дата: 2026-10-31. Статус: принято по решению владельца.

Контекст: ручная выдача лицензий (ADR 0001) создаёт для владельца постоянные ожидания. Владелец хочет, чтобы доверенные люди из сообщества проверяли данные и выдавали лицензию вместо него.

Решение: в админке отдельная роль `issuer`.
- Может: просматривать заявки, выдавать лицензию в рамках уже оплаченной заявки, продлевать до выставленного срока.
- Не может: видеть платежи и финансовые отчёты, отзывать ключи, менять тарифы и промокоды, управлять пользователями, видеть персональные данные сверх нужного для выдачи.
- Все действия пишутся в журнал с именем исполнителя.
- Отзыв, возврат и исправление ошибок выдачи делает только владелец.

Риск: сотрудник может выдать ключ по неоплаченной заявке. Смягчаем журналом и лимитом выдач в сутки; проверка оплаты остаётся ручной (владелец или выписка), пока нет автоматизации.
