# Дорожная карта после прототипа

Сроков нет. Порядок отражает зависимости, а не обещания. Обновляется по мере работы и по обратной связи сообщества.

## Сейчас (прототип)
Сделано и проверено на Ubuntu 22.04: управление серверами LinuxGSM из панели, подхват, вход с 2FA, установщик с подписью и откатом, сервер лицензий, Discord-сервер и бот для ролей. Подробности в `docs/prototype-findings.md` и `CHANGELOG.md`.

## До первого публичного релиза (v0.1)
1. ~~Панель и лицензии вместе~~ **сделано в прототипе:** страница «Лицензия», активация, суточное продление, грейс, функции Pro в токене (лимита серверов нет, open core) (проверено сквозным прогоном панели и сервера лицензий). Осталось: вшить публичный корневой ключ владельца и развернуть сервер лицензий на VPS.
2. ~~Выдача лицензий~~ **сделано в прототипе:** веб-интерфейс сервера лицензий (владелец и issuer, обязательная 2FA, номер заказа, суточный лимит, журнал с цепочкой хешей). Осталось: развернуть на VPS после появления корневого ключа, команда `admin-disable`, список отозванных онлайн-ключей.
3. **Бэкапы и расписание:** расписание бэкапов, перезапусков и проверки обновлений **сделано** (ежедневно в заданное время UTC или каждые N часов, один раз при пропуске, результат виден на странице, журнал). Осталось: выгрузка бэкапов во внешнее S3, вайпы по расписанию.
4. **Обновление и откат игры:** снимок перед `update`, откат одной кнопкой; закрепление версии там, где это позволяют LinuxGSM и SteamCMD.
5. ~~Установка новых серверов из панели~~ **сделано** (каталог LinuxGSM, фоновая задача с журналом, зависимости из списков LinuxGSM; проверено на Minecraft). Осталось: проверка на Steam-играх, дополнительные пакеты, i386.
6. **Автообновления панели** (сейчас повторный запуск установщика): проверка подписи, канал stable/beta, откат.
7. **Чистка и безопасность:** тесты на устойчивость (враждебные пути, большие вводы), разбор логов, проверка `staticcheck` и `govulncheck` в CI, независимый просмотр кода.
8. **Документация, сайт, подписанный релиз, юридические документы после проверки юристом** (`legal/`), уведомление РКН.

## v0.2 и дальше
- Менеджер модов (первым Factorio mod portal), вайпы по расписанию из интерфейса.
- Мониторинг ресурсов и онлайна, публичная страница статуса.
- Команды бота Discord (статус, запуск/остановка), уведомления в Discord через вебхуки, выдача ролей по лицензии.
- Публичный REST API и токены доступа.
- Мультиузлы (агент на каждой машине с тем же протоколом helper по mTLS) и тариф Hosting.
- Телеметрия только opt-in и анонимная, с кнопкой «что отправляется».

## Не планируем
Мультитенантный хостинг с биллингом клиентов, Windows-серверы, собственный магазин плагинов, платный Docker-режим.

## Открытые решения владельца
Лицензия проекта (открытый код с платными функциями или source-available), цены Pro, выбор Boosty и FunPay, подача уведомления РКН, зарубежный выход для Discord (сейчас VPN владельца).
