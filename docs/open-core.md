# Открытое ядро и Pro-модуль

Ядро знает только имена функций (`pkg/license/features.go`) и умеет спросить «включена ли функция». Реализации Pro подключаются сборкой с тегом `pro` из приватного репозитория и ядру не нужны, чтобы работать.

- `entitlement.Manager.Has(feature)` отвечает, есть ли у лицензии функция. Нет лицензии или она истекла: ответ «нет», игровые серверы при этом никогда не останавливаются.
- Функция Pro в интерфейсе без модуля показывается как недоступная с пояснением, а не скрывается молча.
- Модуль Pro регистрируется из файла с `//go:build pro` в `cmd/stokehold`; в открытом репозитории такого файла нет.

Что открыто: панель, helper, установщик, подпись релизов, расписания, редактор конфигов, бот ролей Discord, клиентская часть лицензий (проверка токена).
Что закрыто: функции Pro, сервер лицензий и его админка.
