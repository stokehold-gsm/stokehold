# Открытое ядро и Pro

Публичный репозиторий (AGPL-3.0) собирается и работает сам. Pro лежит в приватном репозитории `stokehold-gsm/stokehold-pro` и накладывается на ядро при сборке с тегом `pro` (ADR 0007).

- `pkg/license/features.go` перечисляет функции, `entitlement.Manager.Has(feature)` отвечает, включена ли функция. Нет лицензии или она истекла: «нет», игровые серверы при этом никогда не останавливаются.
- В Free-сборке страниц Pro нет: маршруты дают 404, в меню нет ссылок. Лицензия Pro без Pro-сборки ничего не включает, и страница «Лицензия» это показывает.
- Pro-сборка регистрирует свои маршруты через `proRoutes`, страницы через шаблоны `pages_pro.html`, свои таблицы через `editionTables`.

Открыто: панель, мониторинг, helper, установщик, подпись релизов, расписания, редактор конфигов, бот сообщества, клиентская часть лицензий, сервер лицензий.
Закрыто: REST API и ключи, несколько машин и агент, менеджер модов, вебхук Discord, команды Discord к панели, публичная страница состояния. Позже: бэкапы в S3 и откат обновлений.

Как собрать Pro: в приватном репозитории `./build.sh путь/к/публичному/чекауту`. Сборка отдаёт `stokehold-pro-linux-*` и `stokehold-agent-pro-linux-*`; они выдаются владельцам лицензий вручную.
