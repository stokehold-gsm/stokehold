## D. Главные риски
- Ядро под AGPL-3.0, Pro-модуль закрыт (ADR 0005). Остаётся показать юристу CLA и политику названия.
- Discord из России доступен только через обходные средства; единственная площадка сообщества.
- Продажи через FunPay несут риск блокировки аккаунта и заморозки денег; Boosty без API, выдача вручную.
- Лимит 2,4 млн ₽ в год на НПД: при росте нужен ИП.
- Проект написан с помощью ИИ-ассистента: пометки там, где требуют площадки, и независимая проверка безопасности перед платным запуском.
- Не проверены Steam-игры и крупные игровые данные при бэкапах.
