# Частые вопросы

**Что это?** Веб-панель для игровых серверов поверх LinuxGSM: один бинарник и SQLite.

**Какие игры поддерживаются?** Все, что поддерживает LinuxGSM (143 на момент проверки, список на linuxgsm.com/servers). Панель вызывает скрипт сервера и разбирает его вывод. Для каждой игры нужные зависимости ставит LinuxGSM по подсказке.

**Нужно ли ставить Docker?** Нет. Игровые серверы работают под обычными пользователями Linux, как в LinuxGSM. Это проще и легче, но изоляция слабее, чем в контейнерах: см. документацию по безопасности.

**Могу ли я подхватить сервер, который уже работает?** Да. Вы вносите имя пользователя в `/etc/stokehold/adopt.conf`, панель находит скрипты LinuxGSM и управляет ими. Ничего не переустанавливается и не перезаписывается. Для самого сервера панель выполняет команды LinuxGSM, при запуске которых скрипт может обновить свои модули из GitHub (так устроен LinuxGSM).

**Что с обновлениями игры?** Проверка `check-update` есть. Откат из снимка и закрепление версии в плане, их ещё нет.

**Что бесплатно?** Ядро панели под AGPL-3.0, без лимита серверов. Платный Pro добавляет функции вроде S3-бэкапов и отката. Цены не объявлены.

**Что отправляется на ваши серверы?** Free не отправляет ничего. Pro для проверки ключа отправляет ключ, публичный ключ экземпляра и версию панели. Проверка обновлений и статистика, когда появятся, выключены по умолчанию.

**Что будет, если сервер лицензий недоступен?** Игровые серверы, расписания и бэкапы продолжают работать. Платные функции работают до конца срока последнего подтверждения и ещё 30 дней, затем остаются функции Free.

**Работает ли без Discord?** Да. Discord это только сообщество.

**Почему Discord, а не Telegram или VK?** Решение автора. Из России Discord открывается через обход блокировок; баги и вопросы можно оставлять в GitHub.

**Как проверить, что скачанный файл настоящий?** Установщик сам проверяет подпись релиза и хеши. Если подпись не сходится, установка прекращается до любых изменений.

**Кто пишет и как?** Один разработчик, с помощью ИИ-ассистента. Решения, проверка и релизы на человеке.
