# Первые шаги

## 1. Создайте владельца
Откройте ссылку, которую напечатал установщик (`https://АДРЕС:8443/setup?code=…`): код уже подставлен. Браузер предупредит о сертификате, это нормально, пока у панели нет домена. Если ссылку потеряли, код всегда есть в журнале: `journalctl -u stokehold | grep "setup code"`. Введите почту и пароль (не короче 10 символов). Страница работает один раз: когда владелец создан, повторно её открыть нельзя.

## 2. Включите двухфакторную защиту
Страница «Безопасность» → «Начать настройку». Добавьте показанный секрет в приложение-аутентификатор (Aegis, FreeOTP, любое TOTP), введите шестизначный код и нажмите «Включить». Каждый код можно использовать один раз; отключение защиты требует пароль.

## 3. Добавьте сервер
Страница «Серверы» → «Добавить сервер».

**У вас уже стоит сервер LinuxGSM** (подхват). Панель не имеет права управлять чужими аккаунтами сама: владелец машины вносит имя пользователя в файл, который читает служебный процесс и который не может изменить сама панель:
```
echo factorio | sudo tee -a /etc/stokehold/adopt.conf
```
Затем введите это имя пользователя Linux в панели, нажмите «Найти серверы» и добавьте нужный скрипт (`fctrserver`, `mcserver` и т. п.). Файл читается при каждом запросе, перезапуск не нужен. Подхваченный сервер получает режим `adopted`. Панель не устанавливает ничего в такой аккаунт и не создаёт пользователей.

**Аккаунты `gs_*`**, созданные самим служебным процессом, доступны без внесения в список.

## 4. Управляйте
В списке серверов у каждого есть кнопки: Статус, Запустить, Остановить, Перезапустить, Бэкап, Проверить обновление. Роль `viewer` видит только Статус и Проверку обновления. Все действия попадают в журнал.

Важное про LinuxGSM: команда `backup` останавливает игровой сервер и запускает его снова. `stop` сразу после запуска может не успеть остановить игру штатно и тогда процесс будет убит.

## Роли
- **owner**: всё.
- **admin**: управление серверами.
- **viewer**: только чтение статуса.

Владелец создаёт пользователей на странице «Пользователи»: пароль генерируется и показывается один раз, передайте его лично. Там же сброс пароля и 2FA и удаление. Последнего владельца удалить нельзя. Каждый пользователь меняет свой пароль на странице «Безопасность», при этом остальные его сессии завершаются.

## Язык
Переключатель RU/EN в шапке; выбор запоминается в cookie.

## Лицензия
Страница «Лицензия» показывает тариф, включённые функции и срок. Бесплатный тариф Free: всё открытое ядро без лимита серверов, ключ не нужен, никаких обращений к серверу лицензий. Если вы купили Pro, владелец вводит ключ на этой странице. Что именно отправляется на сервер лицензий, написано на самой странице. Если сервер лицензий недоступен, игровые серверы продолжают работать, а платные функции работают в льготный период. Если лицензия кончилась, пропадают только платные функции; игровые серверы не останавливаются никогда.

## Расписание
У каждого сервера есть страница «Расписание»: бэкап, перезапуск или проверка обновления каждый день в заданное время (UTC) или каждые N часов. Если панель была выключена в назначенное время, действие выполнится один раз после запуска. Помните, что бэкап LinuxGSM останавливает игровой сервер и запускает его снова, выбирайте время без игроков. Результат последнего запуска виден на той же странице. Менять расписание могут owner и admin, viewer только смотрит.

## Установка нового сервера и редактор конфигов
**«Установить новый сервер»** на странице серверов: выберите игру из каталога LinuxGSM и название. Панель создаст отдельного пользователя `gs_...`, поставит пакеты, которые LinuxGSM указывает для игры, и установит сервер; ход установки виден на странице. Идёт одна установка за раз. Если установка не удалась, причина в журнале, повторите с тем же или другим названием. Для Steam-игр LinuxGSM иногда просит дополнительные пакеты: поставьте их вручную по его подсказке. Для Minecraft перед первым запуском нужно принять EULA самому: в редакторе откройте `serverfiles/eula.txt` и поставьте `eula=true`.

**«Файлы»** у сервера: правка конфигов (только внутри `serverfiles` и `lgsm/config-lgsm`, только текст до 256 КБ). Перед сохранением панель оставляет копию прошлой версии рядом (`.stokehold-bak`). Изменения вступают в силу после перезапуска сервера. Файлы видят и меняют только owner и admin, в конфигах бывают пароли. Редактор не создаёт новых файлов и не следует символическим ссылкам.
