# Файловый менеджер

Ссылка «Файлы» у сервера открывает всю папку игрового пользователя Linux: проходить по папкам, создавать, читать, скачивать, загружать, переименовывать и удалять файлы прямо из браузера. Доступно ролям `owner` и `admin`: в конфигах и папках сервера бывают пароли и миры. `viewer` раздел не видит.

## Что можно делать
- **Навигация.** Путь сверху кликабелен, ссылка «На уровень выше» ведёт в родительскую папку. Папки идут первыми, колонки «Имя», «Размер» и «Изменён» сортируются щелчком по заголовку (повторный щелчок меняет порядок).
- **Новая папка** и **новый пустой файл** в текущей папке. Если файл с таким именем уже есть, он не перезаписывается.
- **Загрузить файлы.** Можно выбрать сразу несколько. За один раз не больше **256 МБ** суммарно; файл попадает на место целиком только после последней части, поэтому оборванная загрузка не портит старую версию. Если файл с таким именем уже есть, он заменяется (права сохраняются).
- **Скачать.** Файл отдаётся потоком, размер не ограничен.
- **Изменить.** У текстовых файлов внутри `serverfiles` и `lgsm/config-lgsm` (до 256 КБ) есть ссылка «Изменить» с прежним редактором. Перед сохранением панель оставляет копию прошлой версии рядом (`.stokehold-bak`). Список таких конфигов дублируется внизу корневой страницы.
- **Переименовать и переместить.** Введите новое имя или путь другой папки внутри сервера. Существующий файл не перезаписывается.
- **Удалить.** Каждое удаление просит подтверждения: на отдельной странице видно, что именно будет удалено. Можно отметить несколько элементов и удалить их разом (до 200). Корзины нет, папки удаляются со всем содержимым.

Все изменения и скачивания пишутся в журнал панели (`file.mkdir`, `file.touch`, `file.upload`, `file.rename`, `file.delete`, `file.download`). Содержимое файлов в журнал не попадает.

## Ограничения и защита
- Менеджер видит только домашнюю папку игрового пользователя. Выйти из неё нельзя: ни через `..`, ни через ссылки (символические ссылки показываются как ссылки и никогда не раскрываются). Удаление ссылки удаляет саму ссылку, а не то, на что она указывает.
- Скрыты и недоступны `.ssh`, `.bashrc`, `.profile`, `.bash_profile`, `.bash_logout` и `authorized_keys`: через них можно исполнить чужой код или получить доступ по SSH.
- Домашнюю папку целиком удалить или переместить нельзя.
- Новые файлы и папки принадлежат игровому пользователю, а не root.
- Показываются первые 5000 элементов папки. Загрузка больше 256 МБ за раз отклоняется, большие файлы лучше класть по SSH.
- Работает и для серверов на других машинах (через агента).

## Если что-то не получилось
- «Не получилось: сервер отказал или такого пути нет»: проверьте имя и что родительская папка существует (менеджер создаёт одну папку за раз).
- Загрузка не проходит с ошибкой про размер: отправьте файлы меньшими группами.
- Скачивание оборвалось на середине: файл могли изменить во время скачивания, повторите.
