# Установка

Релиза ещё нет, поэтому установка работает только из собранных вручную файлов (см. `docs/release.md`). Когда выйдет релиз, процесс будет таким.

## Требования
- Linux с systemd: Ubuntu 22.04 и новее или Debian 12 и новее (нужен OpenSSL 3).
- Процессоры amd64 или arm64, root-доступ.
- Для игровых серверов: tmux, curl и то, что попросит LinuxGSM для выбранной игры. Панель сама ничего не ставит без вашей команды.
- Рекомендуется отдельный VPS или машина с игровыми серверами. Минимум для самой панели скромный (десятки мегабайт памяти), игровые серверы требуют своего.

## Установка
```
curl -fsSL https://dl.stokehold.online/install.sh -o install.sh
less install.sh        # прочитайте, что он делает
sudo bash install.sh
```
Что делает установщик:
1. проверяет подпись `SHA256SUMS` и хеши файлов; при любой ошибке останавливается и ничего не устанавливает;
2. кладёт `stokehold` и `stokehold-helper` в `/usr/local/bin`;
3. создаёт пользователя `stokehold`, каталог `/var/lib/stokehold`, файл `/etc/stokehold/stokehold.env`;
4. создаёт и включает сервисы `stokehold-helper` (от root, узкий набор операций) и `stokehold` (от `stokehold`, слушает только `127.0.0.1:8080`);
5. ждёт ответа `/health`.

Параметры: `--channel stable|beta`, `--version vX.Y.Z`, `--no-start`.

## HTTPS
Панель слушает только локальный адрес. Поставьте обратный прокси с HTTPS, например Caddy:
```
panel.example.com {
    reverse_proxy 127.0.0.1:8080
}
```
Файл `/etc/stokehold/stokehold.env` по умолчанию содержит `STOKEHOLD_FLAGS=-secure -trust-proxy`: cookie помечаются Secure, адрес клиента берётся из заголовка прокси. **Для просмотра по обычному HTTP без прокси** уберите `-secure` и `-trust-proxy` и выполните `sudo systemctl restart stokehold`, но не оставляйте так на сервере, доступном из интернета.

## Обновление
Повторный запуск `install.sh`. Установщик сохраняет прежние бинарники, а если новая версия не ответила на `/health` за 20 секунд, возвращает их.

## Удаление
```
sudo bash uninstall.sh            # данные панели остаются
sudo bash uninstall.sh --purge    # и данные панели тоже
```
Игровые серверы и их пользователи не затрагиваются никогда.
