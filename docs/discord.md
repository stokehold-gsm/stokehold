# Discord-сервер проекта

Единственная площадка сообщества (решение владельца). Панель, лицензии и обновления от Discord не зависят; критичные уведомления дублируются в панели и в GitHub Releases.

Сервер «Stokehold GSM», guild id в CLAUDE.md. Раскладка в `internal/discordsetup/plan.go`, тексты в `texts.go`.

## Структура
Основной язык русский, английский вынесен в отдельную категорию. Языковых префиксов в названиях нет.

| Категория | Каналы | Доступ |
|---|---|---|
| 📌 ИНФОРМАЦИЯ | приветствие, правила, роли, новости, релизы, faq, планы | читать всем, писать модераторам и боту |
| 💬 СООБЩЕСТВО | общение, игры, серверы-участников | всем |
| 🛠 ПОДДЕРЖКА | помощь, баги, идеи, гайды | всем |
| 🌍 ENGLISH | start-here (приветствие, правила, FAQ), chat, help, bugs, ideas, guides | start-here только чтение |
| ⭐ ПОДДЕРЖАВШИЕ | бета-тест (Beta tester), pro-зал (Pro, Hosting) | по ролям |
| 🔊 ГОЛОСОВЫЕ | Общий, Помощь голосом, Играем | всем |
| 🛡 ПЕРСОНАЛ | модераторы, журнал, бот | только Moderator |

Оформление: названия вида `💬・общение`, заголовки категорий с эмодзи, закреплённые сообщения в виде цветных карточек (embed) со ссылками на каналы.

## Роли
Персонал и тарифы (выдаёт владелец или бот по лицензии, кнопкой не берутся): Founder, Moderator, Hosting, Pro, Beta tester, Free.
Самовыдача кнопками в `🎭・роли`: язык (🇷🇺 Русский, 🇬🇧 English), уведомления (🔔 Releases, 📣 News), игры (Factorio, Minecraft, Rust, Valheim, CS2). Список разрешённых ролей зашит в `plan.go` (`SelfRoles`), тест проверяет, что тарифные и служебные роли туда не попадают.

## Бот
Приложение `Stokehold` (id в CLAUDE.md), приватное, помечено как бот, в описании сказано, что это бот. Приглашается с правами `2252900130712594`. Токен только в `.env` (локально) и `/etc/stokehold/bot.env` (сервер, права 0600).

Две части:
- `cmd/discord-setup` расставляет каналы, роли и закрепы. Идемпотентен, существующее не меняет.
- `cmd/stokehold-bot` (HTTP, без gateway): принимает нажатия кнопок на `https://api.stokehold.online/discord/interactions`. Проверяет подпись ed25519 и свежесть запроса (5 минут), выдаёт или снимает только роли из `SelfRoles`. Развёртывание: `deploy/stokehold-bot.service` (systemd, DynamicUser, ограничения) и `deploy/Caddyfile` (HTTPS).

## Блокировка Discord и обход
С российского VPS (stokehold.ru) `discord.com` и Telegram не открываются, GitHub и Google работают (проверено 2026-10-31). Входящие запросы от Discord к нашему адресу доходят, исходящие вызовы бота к Discord API нет. Решение: на VPS стоит клиент xray (VLESS+Reality) к VPN-серверу во Франкфурте, локальный SOCKS на 127.0.0.1:1080, и **только** сервис бота ходит через него (`deploy/examples/bot-proxy.conf`, `deploy/xray.service`). Остальной трафик и SSH идут напрямую. Проверено: кнопка выдаёт и снимает роль.

Примечания:
- На VPN-сервере создан клиент `stokehold-vps` в существующем inbound x-ui (перед правкой сделана копия базы `/etc/x-ui/x-ui.db.bak-pre-stokehold-*`). UUID клиента не хранится в репозитории: локально `~/.stokehold-secrets/`, на VPS `/etc/xray/config.json` (0640 root:xray).
- Другой сервер owner-host-3 достаёт Discord напрямую, но владелец запретил его трогать, он в схеме не используется.
- Для российских участников Discord по-прежнему доступен только через обход блокировок. Это риск единственной площадки сообщества, решение о которой принято владельцем.

## Запуск
```
discord-setup -invite-for <APP_ID>                           # ссылка приглашения бота
DISCORD_BOT_TOKEN=... discord-setup -guild <ID>              # расстановка (повторно безопасно)
DISCORD_BOT_TOKEN=... discord-setup -guild <ID> -remove-legacy -clean-defaults
```
`-remove-legacy` удаляет каналы и категории прежних раскладок из `Plan.Legacy`, `-clean-defaults` стандартные пустые каналы нового сервера. Остальное не трогают.

## Модерация
Правила в `📜・правила`, памятка модератора в `🛡・модераторы`. Автомодерацию Discord включает владелец (Настройки сервера → Модерация → AutoMod). Права Manage Server боту намеренно не выданы.

## Модерация, магазин и журналы (2026-10-31)
Игровых ролей больше нет: остались язык и уведомления. Иерархия персонала (Founder, Curator, Moderator, Helper) и ветка магазина (Shop Curator, Shop Operator) описаны в docs/moderation.md и docs/shop-operations.md. Бот теперь умеет:
- slash-команды модерации `/warn /warnings /timeout /untimeout /kick /ban /unban /purge` (регистрация: `discord-setup -guild ID -register-commands APP_ID`);
- тикеты магазина: кнопка в `🛒・купить-лицензию`, приватный канал на клиента;
- копирование журнала аудита в `📜・события`.
Переменные сервиса бота: `DISCORD_APP_ID`, `DISCORD_GUILD_ID`, `STOKEHOLD_BOT_WARNS` (файл предупреждений) рядом с токеном и публичным ключом. Обновить тексты закрепов: `discord-setup -guild ID -repost`; убрать игровые роли: `-remove-legacy`.
