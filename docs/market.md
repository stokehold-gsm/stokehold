## Что видно из найденного

- AMP - ближайший по идее продукт («просто, много игр»), и он закрыт для России. Это самая чёткая ниша. Обходной путь через Patreon есть, но для российской карты он вряд ли рабочий **[не проверено]**.
- Pterodactyl/Pelican мощные, но рассчитаны на хостинг с биллингом и несколькими узлами. Для админа на одном VPS избыточны.
- Pterodactyl регулярно ловит критические уязвимости: CVE-2025-49132 в Panel, неавторизованный RCE, CVSS 10.0, исправлено в 1.11.11, эксплойты публичные [11]; CVE-2024-27102 в Wings, path traversal с выходом из песочницы, CVSS 9.9, исправлено в 1.11.9 ценой переписывания файловой подсистемы [12]. Урок для архитектуры: файловые операции только через один модуль с жёсткой привязкой к корню сервера, а публичных эндпоинтов без авторизации минимум.
- Лёгкие панели (PufferPanel, Crafty) либо без широкой поддержки игр, либо только Minecraft.
- LinuxGSM даёт 143 игры бесплатно и под MIT. Панель поверх него закрывает «сотни игр без своих шаблонов», в отличие от eggs Pterodactyl, которые поддерживают вручную.

Предположительные пробелы (**гипотезы, нужна проверка перед тем, как строить на них позиционирование**):
1. Панель «поверх существующего LinuxGSM», которая подхватывает уже стоящие серверы, ничего не переустанавливая. Ни у кого из изученных не нашёл.
2. Закрепление версии игры и откат одной кнопкой.
3. Нормальный русский интерфейс и документация под российские реалии (оплата, блокировки).
4. Лёгкая установка плюс безопасность по умолчанию.

## Сегменты

- **Админ-одиночка (1-3 сервера, 5-20 игроков).** Боль: версии, бэкапы, моды через SSH. Готовность платить низкая, но реальная, если цена порядка стоимости пары чашек кофе в месяц. Это я сам, поэтому самый понятный сегмент.
- **Сообщество (3-10 серверов, несколько админов).** Нужны роли, журнал действий, расписание вайпов, уведомления в Discord. Платят из общего кармана сообщества, чаще разово или через донат-подписку.
- **Мелкий хостинг (десятки клиентов).** Нужны мультиузлы, клиентские аккаунты, биллинг. Здесь Pterodactyl/Pelican сильны, лезть туда в MVP не стоит. Только позже.

Объём каждого сегмента и реальная готовность платить **не измерены**. Единственный честный способ - спросить в Discord-сообществах админов до того, как писать платный функционал.

## Гипотезы цен (в рублях, **не проверены спросом**)

Ориентир: AMP Standard $10 разово и Professional $30 разово [8] (то есть разовая лицензия, а не подписка).

- **Free:** 1-2 игровых сервера, все базовые функции (запуск, консоль, бэкапы на диск, расписание). Нужен, чтобы продукт распространялся.
- **Pro:** до ~10 серверов, бэкапы в S3, откат версий, Discord-бот, несколько админов. Идея: либо ~300-500 ₽/мес, либо разовая лицензия ~2 500-4 000 ₽ с годом обновлений. Выбор зависит от того, какой способ оплаты заработает (ниже).
- **Hosting:** отложен.

Принцип: ничего критичного для уже запущенных серверов не отключаем при пропаже лицензии (грейс-период, см. фазу 4).

## Приём платежей из России

Что удалось подтвердить:

- **Boosty:** официального публичного API и вебхуков не нашёл. Есть только неофициальные клиенты на внутреннем API, который может измениться в любой момент [13]. Строить автоматическую проверку подписки на нём рискованно, и использование внутреннего API может нарушать правила площадки. Boosty пригоден как канал добровольной поддержки, но не как лицензирование.
- **ЮKassa:** автоплатежи есть, но по умолчанию только в тестовом магазине; в боевом включаются через менеджера, и нужна оферта с условиями подключения и отмены [14]. Комиссия «от 0,4% + НДС» по одному каталогу, **нужно проверить на сайте** [15]. Про вебхуки автоплатежей на странице ничего нет, смотреть общую документацию.
- **Чеки самозанятого:** по статье на Хабре, ЮKassa убрала автофискализацию для самозанятых в конце 2025, чек остаётся на мне; публичного API у «Мой налог» нет, только недокументированный внутренний [16]. Это **нужно подтвердить по первоисточникам**: от этого зависит, самозанятый я или ИП.
- **Продамус:** позиционируется на самозанятых и ИП, цены подключения в источниках расходятся (10 000 ₽ против акции за 1 ₽), комиссия по картам ~3,5% [16]. Документацию API и подписок открыть не удалось (404), **не проверено**.
- **CloudPayments, Robokassa, T-Банк Касса, Tribute и другие:** не изучены.

Предварительный вывод: для автоматической выдачи лицензий нужен провайдер с официальным API, вебхуками с подписью и автоплатежами, а не Boosty. Схема по умолчанию: разовые лицензионные ключи (проще юридически и технически, нет автосписаний), ключ выдаёт мой сервер по вебхуку оплаты. Подписки добавим, если спрос покажет, что разовые не окупают поддержку. Окончательный выбор провайдера - после проверки документации и после того, как ты решишь самозанятость или ИП (вопрос в `TODO_FOR_HUMAN.md`).
