## До первого релиза и до первых продаж
4. **Ключ подписи релизов:** на своей машине `go run ./cmd/stokehold-sign keygen release.key release.pub` (docs/release.md); приватный ключ хранить офлайн в двух копиях, публичный вставить в `install/install.sh`. Без этого установщик работает только с `--pubkey`.
5. **Корневой ключ лицензий:** `go run ./cmd/stokehold-sign keygen root.key root1.pem`; `root1.pem` положить в `internal/entitlement/roots/` (публичный, в git), `root.key` хранить офлайн. Затем `stokehold-license online-key ...` даёт `online.json` для сервера лицензий (docs/licensing-ops.md). Без этого панель работает только как Free.
6. **Выбрать лицензию проекта:** открытый код (AGPL или MIT) с платными функциями по ключу, либо source-available. Влияет на EULA, README и список в awesome-selfhosted.
7. **Юридическое:** показать юристу `legal/` и подставить ФИО, ИНН, почту; прочитать `legal/owner-memo.md`. **Подать уведомление в Роскомнадзор** до запуска сервера лицензий: исключения из ст. 22 152-ФЗ к нашей базе не подходят.
8. **Площадки оплаты:** прочитать правила FunPay (funpay.com/trade/info) и Boosty про продажу лицензий на ПО, затем создать лоты. На каждую оплату формировать чек в «Мой налог», формулировку наименования уточнить в ФНС.
9. **Товарный знак:** поискать «Stokehold» в реестре Роспатента.
